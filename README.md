# SplitEasy - Expense Splitter App

## 📌 Project Overview

SplitEasy is a simple expense splitting application where users can: -
Create groups - Add members - Add expenses - Split expenses among
members - View balance summary

------------------------------------------------------------------------

## 🖥️ Frontend (Flutter)

Built using Flutter.

Features: - User login & group dashboard - Create group & add members -
Add expense with split options - View summary with balances

Main Folder:

    frontend/

------------------------------------------------------------------------

## 🔧 Backend (PHP + MySQL)

Built using PHP APIs and MySQL database.

APIs Included: - Register / Login - Create Group - Add Member - Add
Expense - Get Expenses - Get Balances

Main Folder:

    backend/


------------------------------------------------------------------------

## 🚀 How to Run

### Backend

1.  Place backend folder inside XAMPP htdocs
2.  Start Apache & MySQL

### Frontend

1.  Run `flutter pub get`
2.  Update API base URL
3.  Run `flutter run`
